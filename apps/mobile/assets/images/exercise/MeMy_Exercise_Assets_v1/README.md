# MeMy Exercise Assets v1

This package contains six generated 4:5 exercise-category illustrations in original PNG and mobile-optimized WebP formats.

## Recommended mapping

- `strength-lunge-dumbbells` — Strength Training / featured workout
- `running-cardio` — Running / general cardio
- `yoga-warrior` — Yoga / balance
- `cycling-cardio` — Cycling
- `hiit-bodyweight-squat` — HIIT / legs / home workout
- `mobility-side-stretch` — Stretching / mobility / recovery

Use the WebP files in the Flutter app for smaller bundle size and retain PNGs as masters. These are decorative category and hero illustrations. For exercise-detail screens, create reviewed instructional media showing the actual movement in multiple phases, together with form cues and common mistakes.

Suggested Flutter path: `assets/images/exercise/categories/`.
