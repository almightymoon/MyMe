# Interactive web prototype (design reference)

This directory holds the approved HTML/CSS/JavaScript visual prototype formerly
at the repository root (`index.html` + `app/`).

It is **not** the public production website.

- Production site: `apps/www`
- Generated public branch: `deploy/website` (from `apps/www` only)

Do not deploy `prototype/web` to the VPS or include it in `deploy/website`.
