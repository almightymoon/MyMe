# Working with Goals

Goals help you track personal milestones and optional financial targets.

## Storage

By default goals persist locally on this device. If your build uses the MeMy API (`GOALS_DATA_SOURCE=api`), goals sync to the backend with a local cache.

## Tips

- Add milestones to break large goals down.
- Archive instead of delete when you want history kept.
- Privacy & Data can export or wipe local goals.
