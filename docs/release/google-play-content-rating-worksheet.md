# Google Play Content Rating Worksheet (draft)

Use the IARC questionnaire in Play Console. Suggested intent for MeMy v1:

| Question theme | Suggested answer |
|---|---|
| Violence | No |
| Sexuality | No |
| Language | No |
| Controlled substances | No |
| Gambling / contests | No |
| User interaction / UGC sharing publicly | No public social feed |
| Shares user’s location | No |
| Digital purchases | No (v1) |
| Age-restricted content categories | No |

## Likely outcome

**Everyone** / **PEGI 3** class ratings are typical for a local productivity companion without social UGC. Final rating is assigned by the questionnaire — do not hard-code a certificate ID in this doc until Play issues one.

## Owner actions

1. Complete IARC questionnaire under the Play app listing.
2. Save the rating certificate ID into release notes for the team when issued.
3. Keep store descriptions free of medical claims that could reclassify the app.
